# POLO CHAMPIONS

Playable browser proof-of-concept for a single-player field polo match.

## Run
`npm install` then `npm run dev`

## Production build
`npm run build`

## Controls
- WASD: move and steer
- Shift: gallop (while moving)
- X: brake
- Space: hold/release charged forehand strike
- Q: hold/release backhand strike
- R: reset ball; Esc: pause
- Gamepad: left stick ride, right stick aim, RT accelerate, LT brake, A strike, X power strike, B backhand.

The slice uses low-poly procedural visuals, a third-person camera, ball physics, scoring, and a two-minute match clock. It has no AI opponents or multiplayer.
