# POLO CHAMPIONS — Vertical Slice Plan

## Smallest playable loop
Ride a single horse across a stylized polo field, line up the ball with the aim direction, charge and swing a mallet, then score into either goal before the two-minute clock expires.

## Milestones
1. Establish Vite/React/TypeScript project structure and project rules.
2. Build procedural Three.js field, rider, horse, ball, goals, and camera.
3. Add deterministic movement, aim, mallet shots, goal detection, match clock, and HUD.
4. Add keyboard and Gamepad API input, reset/pause/restart flows.
5. Add smoke coverage, run build validation, and document usage.

## Scope guardrails
Single-player only; no AI teams, online play, accounts, persistence, or backend.
